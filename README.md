# Newtonian-Gravity-Sim 🌌

### Description
This is a **test version (v1)** of my physics-focused web project.  
The goal of this project is to experiment with and visualize the **Universal Law of Gravitation** in code.

The simulation is based on classical **Newtonian mechanics** and serves as a learning and testing environment rather than a finished product.

This project was mainly a learning experience where I practiced:
- Implementing Newton’s Universal Law of Gravitation  
- Custom physics calculations without built-in engines  
- Force, mass, and acceleration relationships  
- Early-stage simulation logic and structure  

### Formula Used
The core formula implemented in this project:

F = G * (m1 * m2) / r²

Where:
- `F` — gravitational force  
- `G` — gravitational constant  
- `m1`, `m2` — object masses  
- `r` — distance between objects
